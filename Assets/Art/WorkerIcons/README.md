# Worker icon

The source SVG in `SourceSvg/worker.svg` is the **Caveman** icon from
[Game-Icons.net](https://game-icons.net/1x1/delapouite/caveman.html).

- Artist: Delapouite (https://delapouite.com/)
- License: Creative Commons Attribution 3.0 (CC BY 3.0)
- License text: https://creativecommons.org/licenses/by/3.0/

The Unity-ready player variants in `Assets/Resources/WorkerIcons/` retain the
original glyph. They add the same dark circular field, warm outline, uniform
inset, and player accent colors used by the resource-icon set.
